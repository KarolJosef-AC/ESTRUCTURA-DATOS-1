#  Versión Inicial del Proyecto To-Do List

Esta carpeta contiene la **primera versión funcional** del proyecto **To-Do List (Gestor de Tareas)** desarrollada antes de la presentación realizada el **27 de abril de 2026**.

La presente versión representa la etapa inicial del sistema, incluyendo las funcionalidades básicas implementadas en ese momento para la gestión de tareas mediante estructuras de datos dinámicas.

---

##  Contexto

Esta versión fue presentada como avance preliminar del proyecto académico de **Estructura de Datos I**.

Posteriormente, el proyecto recibió múltiples mejoras relacionadas con:

- Optimización del código
- Mejoras en la interfaz
- Corrección de errores
- Mejor organización bajo arquitectura MVC
- Persistencia de datos mejorada
- Nuevas funcionalidades:
      - Filtrado por categoria de tareas
      - Dificultad de tareas
      - Modificar Tareas
